# Fahmida Ahmed Esha — Portfolio

Professional portfolio site for Fahmida Ahmed Esha, Industrial and Production Engineering student at RUET.

Built with [Gatsby](https://www.gatsbyjs.com/).

## Development

```sh
npm install --legacy-peer-deps
npm start
```

Open [http://localhost:8000](http://localhost:8000).

## Content

All site content lives in `content/` (jobs, featured project, honors & leadership) and is sourced from the portfolio brief in `Professional Portfolio_ Fahmida Ahmed Esha.md`.
