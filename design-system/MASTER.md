# Fahmida Portfolio — Design System (Monochrome)

## Palette
| Token | Hex | Usage |
|-------|-----|--------|
| Background | `#000000` | Page, nav |
| Surface | `#141414` | Cards, panels |
| Border | `#2a2a2a` | Dividers, tabs |
| Text primary | `#f5f5f5` | Headings |
| Text body | `#a3a3a3` | Paragraphs |
| Accent | `#ffffff` | Links, buttons, labels |

## Typography
- Sans: Calibre stack
- Mono: SF Mono stack

## Rules
- No color accents outside grayscale
- Minimum 4.5:1 contrast for body text
- Responsive breakpoints: 360, 480, 768, 1080px
- `prefers-reduced-motion` respected (existing)
